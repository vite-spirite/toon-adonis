adonis-toon adds native TOON serialization to AdonisJS for token-efficient, LLM-ready APIs.
- Add `response.toon()` and content negotiation for `application/toon` in AdonisJS v6
- Provide Lucid model mixin for automatic TOON encoding with relations and pagination
- Build schema-based serializer with whitelisting, casting, and validation support
- Include JSON vs TOON token benchmarks and docs for OpenAI and Claude consumption
